# quiz tounsi

Want to know how much you know about tunisia? Want to discover some surreal facts about this exciting country? Look no further! With 4 levels (3 actually :) ), take this interactive quiz instead of doomscrolling and you'll be hella cultivated! Blending history, geography, sports and general culture, Quizz Tounsi (c) demonstrates how the small country of Tunisia has a lot of interesting facts to offer!
